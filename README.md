# Tienda inteligente

Proyecto académico de la asignatura **Inteligencia de Negocios**.

El repositorio alojará progresivamente los recursos y componentes para trabajar la Unidad 4: Machine Learning e Inteligencia Artificial.

## Objetivo

Construir y evaluar una solución empresarial didáctica que integre:

1. Machine Learning.
2. Visión por computadora.
3. Procesamiento de lenguaje natural.
4. Sistemas conversacionales.

## Plan de desarrollo

El primer componente será un generador visual de anaqueles 2D. Se utilizará como escenario controlado para capturar imágenes, experimentar con procesamiento de imágenes y obtener datos para el análisis del negocio.

## Estructura prevista

- `shelf-generator/`: aplicación web del generador de anaqueles.
- `docs/`: documentación técnica y guías de uso.
- `labs/`: materiales de los laboratorios.
- `exam/`: recursos y escenarios de evaluación (se incorporarán cuando corresponda).

## Requisitos del proyecto

- Herramientas gratuitas y, preferentemente, open source.
- Ejecución local siempre que sea posible.
- No depender de servicios externos de pago.
- Mantener instrucciones reproducibles para Windows.

## Estado

Repositorio inicial. El generador todavía está en fase de definición.
